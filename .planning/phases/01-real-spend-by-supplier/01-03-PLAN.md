## Phase Goal

**As a** business owner, **I want to** sign in and sync my Drive invoices, **so that** I see exact spend by supplier and month.

This plan makes "exact spend" provable in CI: the parser and dashboard tests run on faithful, anonymized copies of all 143 real invoices.

<objective>
Build a local-only, deterministic anonymizer and commit 143 anonymized CFDI fixtures plus a leak guard (LEDG-07; CONTEXT "Claude's Discretion" on anonymization: replace RFCs, names and UUIDs, keep structure, BOM, namespaces and amounts).

Purpose: the real files are fiscal data and git-ignored; tests need byte-faithful structure and exact amounts to lock the golden totals (217,880.82 net; the telecom issuer 16,053.07; the ads issuer 13,679.30).
Output: `scripts/build-fixtures.ts`, `tests/fixtures/cfdi/001.xml`..`143.xml`, `tests/fixtures/cfdi/PROFILE.json`, `tests/unit/fixtures-clean.test.ts`.
</objective>

- Input: default the repo-root sample directory (override `--input <dir>`); collect every `*.xml` recursively (year subfolders), sorted by relative path. Decode as UTF-8 bytes but operate on the raw string with the BOM preserved; never parse-and-rebuild (that would lose BOM, declaration, prefixes and schemaLocation).
- Deterministic injective maps built from SORTED real values: issuer RFC (from `Emisor@Rfc`) by sort index i (1-based) to `EMI010101` + base-36 index uppercased and left-padded to 3 chars when the real RFC has 12 chars, or `EMIX010101` + the same 3 chars when it has 13 chars; issuer `Nombre` to `PROVEEDOR NNN SA DE CV` keyed by the issuer's mapped index (the same issuer always gets the same name); every UUID seen anywhere (`TimbreFiscalDigital@UUID`, `CfdiRelacionado@UUID`, `DoctoRelacionado@IdDocumento`) through ONE global map to `AAAAAAAA-0000-4000-8000-` + a 12-digit zero-padded index, preserving case-insensitive identity so E-to-I and P-to-I links survive; each distinct `Concepto@Descripcion` to `CONCEPTO NNNN`.
- Fixed replacements: `Receptor@Rfc` `RCP010101AA1`, `Receptor@Nombre` `RECEPTOR DE PRUEBA SA DE CV`, `Receptor@DomicilioFiscalReceptor` and `Comprobante@LugarExpedicion` `00000`; `Comprobante@Sello` and `TimbreFiscalDigital@SelloCFD`/`SelloSAT` `SELLO`; `Comprobante@Certificado` `CERTIFICADO`; `NoCertificado`/`NoCertificadoSAT` `00001000000000000000`; `TimbreFiscalDigital@RfcProvCertif` `PAC010101AA1`; `Serie` `A` and `Folio` = the fixture number (on Comprobante and DoctoRelacionado); Pagos `RfcEmisorCtaOrd`/`RfcEmisorCtaBen` `BAN010101AA1`, `CtaOrdenante`/`CtaBeneficiario` `0000000000`, `NomBancoOrdExt` `BANCO`; `ACuentaTerceros` RFC `TER010101AA1`, name `TERCERO DE PRUEBA`, domicilio `00000`; `Concepto@NoIdentificacion` `SKU`, `Concepto@Unidad` `Pieza`. If an `Addenda` element exists, empty its content and count it (expected 0).
- Replacement is attribute-scoped: locate each start tag by local name with an optional prefix, then rewrite only the named attributes inside that tag. Amounts, rates, `ClaveProdServ`, `ClaveUnidad`, `Fecha`, `Moneda`, `TipoCambio`, `TipoDeComprobante`, `MetodoPago`, `UsoCFDI`, `RegimenFiscal` stay untouched.

- Output: write `001.xml`..`NNN.xml` (neutral names; the original names embed RFC and UUID) plus `PROFILE.json` (`files`, `tipos` {I,E,P}, `issuers`, `withBom`, `withoutDeclaration`, `singleConcept`, `netTotal` as a decimal string, `months` histogram by `Fecha` slice 0..7) into `tests/fixtures/.cfdi-tmp`, then remove the old `tests/fixtures/cfdi` and rename the temp dir into place (edge LEDG-07/concurrency).
