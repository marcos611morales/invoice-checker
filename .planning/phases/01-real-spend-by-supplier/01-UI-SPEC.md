### Required global CSS changes (the only edits to `src/app/globals.css`)

1. **Fix the font variable.** `@theme inline` currently has `--font-sans: var(--font-sans);` (self-reference) while the font loader defines `--font-geist-sans`. Nothing ever defines `--font-sans`, so `font-sans` on `<html>` resolves to an invalid value and the app falls back to the browser default font. Change to `--font-sans: var(--font-geist-sans);`. Keep `--font-heading: var(--font-sans);`.
2. **Replace the chart tokens.** The shipped `--chart-1: oklch(0.87 0 0)` is near-white grey (contrast about 1.5:1 on white), unusable for bars. In `:root` and in `.dark`:

| Token | `:root` | `.dark` | Use |
|-------|---------|---------|-----|
| `--chart-1` | `oklch(0.52 0.10 215)` (about `#0E7490`, 5.3:1 on white) | `oklch(0.72 0.11 215)` | Every bar in every Phase 1 chart |
| `--chart-2` | `oklch(0.42 0.09 215)` | `oklch(0.80 0.10 215)` | Hovered / active bar |
| `--chart-3..5` | unchanged | unchanged | Not used in Phase 1 (single-series charts) |

No other token is changed. Do not edit primitives in `src/components/ui/*` except through `className` at the call site.

## Spacing Scale

Declared values (multiples of 4). Tailwind step in parentheses.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`1`) | Gap between a name and its RFC line; icon-to-label gaps |
| sm | 8px (`2`) | Compact gaps inside a control cluster; cell vertical padding adds to this |
| md | 16px (`4`) | Default card padding and in-card block gap (shadcn `--card-spacing`); form field gaps |
| lg | 24px (`6`) | Gap between cards (`space-y-6`); header horizontal padding |
| xl | 32px (`8`) | Main content vertical padding (`py-8`) |
| 2xl | 48px (`12`) | Empty-state / onboarding / access-denied vertical padding |
| 3xl | 64px (`16`) | Not used in Phase 1 |

Layout rules:
- App shell: header height 56px (`h-14`), `border-b`. Header and `<main>` content share one container: `mx-auto w-full max-w-6xl px-6` (1152px max). `<main>` adds `py-8`.
- Everything is a single column of full-width cards at every breakpoint. No side-by-side charts in Phase 1.
- Under 640px: header wraps (brand row, then nav row), the email is hidden under 768px, tables and the top-10 chart scroll horizontally inside their card.

Exceptions:
- 12px (`gap-3`) is the **only** non-standard spacing value. It is allowed for header control clusters (email + sign-out) and for the numbered-step circle gap, as it already is in `src/app/(app)/layout.tsx`; it is deliberately not added to the scale table. No other off-scale gap, padding or margin is permitted.
- Control heights follow the shadcn nova preset (`h-8` default, `h-9` for `lg`). This is a desktop-first internal tool, so the 44px mobile touch target is not enforced. Compensation: table rows keep at least 40px height (`py-2` on cells) so row links are comfortable to tap, and the primary button of each screen uses `size="lg"`.
- Chart heights are fixed content boxes, not spacing tokens: monthly chart `h-[280px]`, top-10 chart `h-[400px]`.

## Typography

Four sizes, two weights. Money, counts, percentages and the sync counter always carry `tabular-nums`.

| Role | Size | Weight | Line Height | Used for |
|------|------|--------|-------------|----------|
| Caption | 12px (`text-xs`) | 400 | 1.5 (`leading-normal`) | RFC under a supplier name, "Última sincronización", help text, chart tick labels, badges |
| Body | 14px (`text-sm`) | 400 | 1.5 (`leading-normal`) | Table cells, form text, alerts, descriptions, nav links, summary counts; also **card titles at weight 600** (`CardTitle` gets `className="text-sm font-semibold"`; the shipped 16px/500 default is overridden) |
| Heading | 20px (`text-xl`) | 600 | 1.2 (`leading-[1.2]`) | Page `h1` ("Gasto por proveedor", "Ajustes", the supplier name), onboarding card title |
| Display | 30px (`text-3xl`) | 600 | 1.2 (`leading-[1.2]`) | The hero total ("$217,880.82"), the login and "Acceso denegado" `h1` (already built) |

Weights: **400** (regular) and **600** (semibold, `font-semibold`) only in authored markup. Exception: the generated shadcn primitives (`Button`, `Badge`, `Label`, `TableHead`) ship at 500 internally; this is accepted and must not be copied into authored class lists.

Rules:
- Muted text uses `text-muted-foreground`. Never place 12px muted text on a `muted` (grey) surface (contrast 4.4:1); put it on white / card only.
- Supplier names are shown exactly as the SAT `Nombre` (usually uppercase). No `uppercase`/`capitalize` transforms.
- Money in tables is right-aligned; text columns left-aligned.

## Color

The existing theme is pure neutral greyscale from the nova preset. It stays; Phase 1 adds exactly one hue, teal (`--chart-1`), reserved for data.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` / `--card` `oklch(1 0 0)` (#FFFFFF) | Page background, every card, the table body |
| Secondary (30%) | `--muted` / `--secondary` `oklch(0.97 0 0)` (#F5F5F5) + `--border` `oklch(0.922 0 0)` (#E5E5E5) + text `--foreground` `oklch(0.145 0 0)` (#0A0A0A) and `--muted-foreground` `oklch(0.556 0 0)` (#737373) | Table header row, row hover (`bg-muted/50`), secondary badge, progress track, step circles, card ring, dividers, text |
| Accent (10%) | `--chart-1` `oklch(0.52 0.10 215)` (about #0E7490); hover `--chart-2` | See reserved list below |
| Destructive | `--destructive` `oklch(0.577 0.245 27.325)` (about #E7000B) | Failure alerts only |

Primary buttons ("Sincronizar" in onboarding, "Guardar carpeta", "Ir a Ajustes", "Iniciar sesión con Google") use the preset `--primary` (near-black `oklch(0.205 0 0)`), not the teal accent. The progress fill also stays `bg-primary`.

Accent reserved for (and nothing else):
1. Bar fill in the three charts (monthly spend, top-10 suppliers, supplier-detail monthly spend); hovered bar uses `--chart-2`.
2. The 2px bottom indicator under the active nav link in the header (`aria-current="page"`).

Destructive reserved for: `Alert variant="destructive"` (sync failure, stalled sync, invalid Drive state, folder not found / not readable). Negative amounts are **not** red: they show the minus sign from `Intl` and the same foreground color, because an Egreso netting a month below zero is a normal business fact, not an error.

Non-color cues: every state conveyed by color is also conveyed by text or icon (alerts carry an icon and a title; "Contado" / "No contado" are words).

Chart styling (all three charts): horizontal grid lines only, `stroke` `var(--border)`; axis lines hidden; tick text 12px `var(--muted-foreground)`; bar corner radius 4px on the free end; `isAnimationActive={false}` (static dashboard, also honors reduced motion); no legend (single series); a zero baseline (`ReferenceLine y={0}` / `x={0}`) in `var(--border)`.

## Screens and Layout

### Shell (`src/app/(app)/layout.tsx`)
Left: brand text "Facturas — Análisis de gastos" (Body, 600; shows only "Facturas" under 640px) as a link to `/`. Next to it, nav links "Resumen" (`/`, also active on `/proveedores/*`) and "Ajustes" (`/ajustes`) — Body 14px, 400; inactive `text-muted-foreground`, active `text-foreground` with the 2px teal indicator and `aria-current="page"`. Nav needs `usePathname`, so it is a small client component (for example `src/components/app-nav.tsx`). Right: the signed-in email (Body, muted, hidden under 768px) and the existing outline "Cerrar sesión" button. `<SessionKeepAlive />` renders nothing.

### Dashboard `/` — data present (`listo` with a non-null DTO), top to bottom
1. **Page header** (flex, wraps, `gap-4`): `h1` "Gasto por proveedor" (Heading); right side, `YearSelect` (inline `Label` "Año" 14px + `Select` 120px wide) and `Badge variant="secondary"` "Montos con IVA (Total del XML)".
2. **Sync strip** — a `Card` (default spacing) containing the whole `SyncButton`: left, the caption line ("Última sincronización: {hora}" / "Aún no se ha sincronizado", Caption); right, `Button variant="outline"` "Sincronizar" with a leading `RefreshCw` icon. When running or finished, the progress / summary block expands inside this same card under a `Separator` (see States).
3. **Card "Gasto por mes"**: `CardHeader` has `CardTitle` "Gasto por mes" and `CardDescription` "Gasto total {anio}". Hero figure below the header: the total in Display (`tabular-nums`). **This hero total is the primary visual anchor (focal point) of `/`**: it is the largest text on the page (30px/600, the only Display element above the fold) and sits at the top-left of the first card, so the eye lands on it before the charts; nothing else on the page may use Display size on the dashboard. Then the 12-month bar chart (`h-[280px]`).
4. **Card "Proveedores principales"**: `CardDescription` "Los 10 proveedores con más gasto en {anio} · montos con IVA". Horizontal bar chart (`h-[400px]`).
5. **Card "Todos los proveedores"**: `CardDescription` "{n} proveedores · montos con IVA". The supplier `Table`.

The `h1` and the visible "Gasto total {anio}" text must exist as text nodes so Plan 01-10's production check ("shows Gasto total 2025") and Plan 01-08's "con IVA" grep both pass.

### Charts
- **Monthly chart** (dashboard and supplier detail share `MonthlySpendChart`): 12 vertical bars Jan to Dec of the selected year, always 12 (months without invoices are zero, no bar drawn, label kept). X ticks `monthLabel` (ene, feb, ... dic). Y ticks `formatMXNCompact`, 12px, width 56px. Tooltip: title `monthLabelLong`, row "Gasto" with `formatMXN`. Container carries `role="img"` and `aria-label` "Gasto por mes en {anio}, montos con IVA".
- **Top-10 chart**: `layout="vertical"`, one bar per supplier, category axis shows the supplier name truncated to 28 characters with an ellipsis (full name in the tooltip), axis width 200px, 12px. A `LabelList` at the bar end shows `formatMXNCompact` so values read without hovering. Tooltip: full name, RFC (Caption), `formatMXN`. Bars are clickable (`cursor-pointer`) and navigate to `/proveedores/{rfc}?anio={anio}`. Because Recharts bars are not keyboard-reachable, the supplier table below is the keyboard and screen-reader equivalent; the chart container is `role="img"` with `aria-label` "Los 10 proveedores con más gasto en {anio}; usa la tabla de abajo para abrir un proveedor". Under 640px the chart sits in an `overflow-x-auto` wrapper with `min-w-[480px]` on the plot.
- **Supplier-detail chart**: same component and look as the monthly chart.

### Supplier table
Columns in order: **Proveedor** (left), **Gasto** (right), **% del total** (right), **Facturas** (right). Header row on `bg-muted`, Body 600 via `TableHead`. Sorted by Gasto descending then RFC ascending; no sortable headers and no pagination in Phase 1 (all rows render; the sample has 39). Proveedor cell: the name as a `next/link` to `/proveedores/{rfc}?anio={anio}` (Body, 400, underline on hover, visible focus ring, `line-clamp-2`), and the RFC under it (Caption, `text-muted-foreground`, `mt-1`). Rows have `hover:bg-muted/50`, cells `py-2`. Money uses `formatMXN`, percent `formatPercent`, all `tabular-nums`. A supplier at exactly $0.00 renders "$0.00" and "0%".

### Supplier detail `/proveedores/[rfc]`
1. A `Button variant="ghost" size="sm"` with `ArrowLeft` icon and text "Volver a proveedores", linking to `/?anio={anio}`.
2. Header: `h1` = supplier name (Heading, `break-words`), RFC under it (Caption muted), then the same "Montos con IVA (Total del XML)" badge and `YearSelect` (only years where this supplier has documents).
3. Two stat blocks side by side in a `Card` (stacked under 640px): "Gasto {anio}" with the amount in Display; "Facturas" with the count in Display.
4. Card "Gasto por mes" with the shared monthly chart.

### Ajustes `/ajustes` (Plan 01-05)
`h1` "Ajustes", then one `Card` (max width 672px, `max-w-2xl`) titled "Carpeta de facturas" with `CardDescription` "Se cuentan los XML de la carpeta y de sus subcarpetas por año."
- **Carpeta actual** block (Body): label "Carpeta actual", the folder name (600) and a `Badge variant="outline"` "Guardada en Drive" or "Predeterminada (variable de entorno)". If none is set, this block is replaced by "Aún no has elegido una carpeta." and, when `suggest()` returns results, a list "Carpetas llamadas Facturas en tu Drive:" with one row per folder (name + `Button size="sm" variant="outline"` "Usar esta carpeta", which fills the field and runs "Revisar carpeta").
- **Form**: `Label` "Enlace o ID de la carpeta de Drive" + `Input` (placeholder `https://drive.google.com/drive/folders/…`), help text (Caption) "Pega el enlace de la carpeta o su ID." Buttons: "Revisar carpeta" (`outline`) and "Guardar carpeta" (`default`, disabled until a review succeeded; editing the field invalidates the review).
- **Review result** (shown under the field, `aria-live="polite"`): "Carpeta: {nombre}" and "{N} XML encontrados (incluye subcarpetas)" (singular "1 XML encontrado"); if shortcuts were ignored, a third line "{k} accesos directos ignorados". If N is 0, an `Alert` (default) titled "No se encontraron archivos XML" with "Puedes guardar la carpeta, pero no habrá facturas que importar."
- **Folder-change notice** (only when a folder already exists and the reviewed one differs): `Alert` (default, `Info` icon) "El resumen mostrará los datos guardados en la nueva carpeta (_app/). La carpeta anterior no se modifica."
- Errors from the service (`entrada_invalida`, `no_encontrada`, `no_es_carpeta`, `en_papelera`, invalid pointer file, Drive authorization expired) render their Spanish `mensaje` verbatim in `Alert variant="destructive"` with a `CircleAlert` icon and title "No se pudo revisar la carpeta" (review) or "No se pudo guardar la carpeta" (save).
- Pending: the pressed button is disabled and reads "Revisando carpeta…" or "Guardando carpeta…" with a `LoaderCircle` spinning icon.
- Success: sonner toast "Carpeta guardada"; the "Carpeta actual" block updates via `revalidatePath`.

## States and Interactions

**YearSelect**: a change calls `router.push` with `?anio=` inside `useTransition`; while pending the select is disabled and the page area has `aria-busy="true"` with `opacity-60`. Years are listed newest first. One year still renders the control.

**SyncButton** (shared by dashboard strip, onboarding, no-data state, nothing else):

| State | UI |
|-------|----|
| Idle, never synced | Caption "Aún no se ha sincronizado"; button "Sincronizar" |
| Idle, synced | Caption "Última sincronización: {formatSyncTime}" (short date + time, America/Mexico_City); button "Sincronizar" |
| Running | Button disabled, text "Sincronizando…", spinning `LoaderCircle`. Under a `Separator`: `Progress` (`h-2`) at `done / total` and the line "Importando {done} de {total}…" (Body, `tabular-nums`, es-MX number format) inside a `role="status"` `aria-live="polite"` region. `Progress` gets `aria-label="Progreso de la sincronización"`. |
| Nothing to import | "Todo está al día" (Body) in place of the bar, with the counts below |
| Done | Counts row (Body): "Nuevas: {n}" · "Sin cambios: {n}" · "Con problemas: {n}"; additionally "Actualizadas: {n}" and "Eliminadas: {n}" only when above 0. Then, if there are problems, the `<details>` "Ver archivos con problemas ({n})". |
| Failed mid-way | `Alert variant="destructive"`, `TriangleAlert`, title "No se pudo completar la sincronización", body = the server `mensaje`, then "Se importaron {done} de {total}. Presiona Sincronizar para continuar." Counts so far stay visible; the button returns to "Sincronizar" and resumes. |
| Stalled | `Alert variant="destructive"` with "La sincronización no avanzó; intenta de nuevo." |

Problem list (`<details>`): summary row "Ver archivos con problemas ({n})" with a `ChevronRight` that rotates when open; the body is a list capped at `max-h-64 overflow-y-auto`; each item is "{fileName} — {mensaje}" (Body; `fileName` has `break-all`) plus a `Badge`: `outline` "Contado" for `total_no_cuadra` and `moneda_extranjera` (the invoice still counts, D-08), `secondary` "No contado" for every other code. There is no cancel button: closing the tab is safe because the sync is resumable.

**Keyboard and focus**: all controls are native or Radix, so Tab order follows DOM order and every control shows the preset focus ring (`focus-visible:ring-3`). Table row links, nav links and the back link are real `<a>` elements. Escape closes the Select; the `<details>` toggles with Enter/Space.

**Motion**: no custom animation. Charts are static (`isAnimationActive={false}`); the only motion is the spinner and the `Progress` width transition.

**Hover / click affordances**: bars in the top-10 chart show `cursor-pointer` and the `--chart-2` fill; table rows highlight on hover; nothing else is clickable without an underline, border or button chrome.
